# JobTrack 📋

A responsive **Job Application Tracker** built with HTML, CSS, and JavaScript.
JobTrack helps users organize job applications, track application status, and monitor their job search progress.

## 🚀 Live Demo

[View JobTrack Live](https://akhileshborude16.github.io/JobTrack/)

## 📸 Features

* ➕ Add job applications
* ✏️ Edit existing applications
* 🗑️ Delete applications
* 🔍 Search applications by company or position
* 🎯 Filter applications by status
* 📊 Track application statistics
* 🔗 Add job posting links
* 💾 Store applications using LocalStorage
* 📱 Responsive design for desktop and mobile
* 🎨 Clean and modern user interface

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, responsive design and animations
* **JavaScript** – Application logic and DOM manipulation
* **LocalStorage** – Client-side data persistence
* **Git & GitHub** – Version control and deployment
* **GitHub Pages** – Hosting

## 💻 How to Run Locally

1. Clone the repository:

```bash
git clone https://github.com/akhileshborude16/JobTrack.git
```

2. Open the project folder:

```bash
cd JobTrack
```

3. Open `index.html` in your browser.

You can also use the **Live Server** extension in VS Code for development.

## 📊 Application Status

JobTrack currently supports the following application statuses:

* Applied
* Interview
* Selected
* Rejected

## 💾 Data Storage

Job application data is currently stored in the browser using **LocalStorage**.

This means the data remains available in the same browser on the same device, but it is not synchronized between different devices.
